      Duration scale

      These tokens are starting heuristics, not universal perceptual thresholds. Tune for distance, size, frequency, task and user needs. Exits often run at roughly two thirds of the matching entrance. Hover a row to see the duration.

      Easing tokens

      A handful of named curves covers almost every case. Name them once in CSS custom properties and reuse them everywhere so the product moves with one voice.

      Standard

      cubic-bezier(0.2, 0, 0, 1)

      Most on-screen movement from A to B.

      Enter (decelerate)

      cubic-bezier(0.05, 0.7, 0.1, 1)

      Things arriving: they rush in and settle gently.

      Exit (accelerate)

      cubic-bezier(0.3, 0, 0.8, 0.15)

      Things leaving: a gentle start, then out of the way.

      Emphasized

      cubic-bezier(0.16, 1, 0.3, 1)

      Hero moments and big reveals; long, luxurious tail.

      Overshoot

      cubic-bezier(0.34, 1.56, 0.64, 1)

      Playful pops on small elements. Never on large surfaces.

      In-out

      cubic-bezier(0.65, 0, 0.35, 1)

      Loops, pendulums and moves that start and end on screen.

      Linear

      linear

      Progress bars, spinners, marquees: mechanical on purpose.

      Steps

      steps(5, jump-end)

      Ticks, typewriters and sprite sheets.

      What properties cost

      Every frame the browser may recalculate style, lay out boxes, paint pixels and composite layers. These are typical paths, not guaranteed GPU promotion or fixed costs. Browser implementation, surface area, rasterization, layers and surrounding content matter; inspect a performance trace.

      PropertyTypical pathNotes
      transformCompositeMove, scale, rotate. Can run off the main thread.
      opacityCompositeFades and crossfades. Pairs with transform for almost everything.
      filter, backdrop-filterPaint / compositeImplementation-dependent; blur radius, area and changing backdrops can increase rasterization cost.
      color, background, box-shadowPaintFine on small elements. Fake big shadows with an opacity-animated layer.
      clip-pathPaint / compositeShape and browser support affect the path; profile large reveals.
      width, height, padding, marginLayoutCan require layout and paint. FLIP can avoid per-frame layout; grid-track height transitions still reflow siblings.
      top, left, font-sizeLayoutUse transform instead of positional offsets.

      Choreography rules

      Eight rules of thumb distilled from the chapters. Break them deliberately, never by accident.

      1. Motion has a jobEvery animation should explain, confirm or direct. If it does none, cut it.
      2. Feedback within 100msAcknowledge input immediately, even when the work takes longer.
      3. Enter slow, leave fastArrivals decelerate; departures accelerate and take about two thirds of the time.
      4. One lead at a timeA single primary motion per moment; everything else supports or waits.
      5. Stagger small, cap the total20–60ms per item and a ceiling for the group, so long lists never drag.
      6. Keep objects continuousNothing teleports: animate from where things were to where they are.
      7. Stay interruptibleUsers change their minds. Retarget from the current position and velocity.
      8. Respect the settingHonour reduced motion with immediate static states or optional short fades, not by deleting feedback.

      Glossary

      Type to filter. Matches highlight in both the term and its definition.

      Anticipation
      A small movement opposite to the main action that prepares the viewer for it, like a wind-up before a throw.
      Choreography
      The coordinated timing of several elements so they read as one gesture rather than a crowd.
      Compositor
      The browser thread that assembles painted layers on the GPU. Transform and opacity animations can run there without the main thread.
      Critical damping
      A damping ratio of exactly 1. For fixed stiffness k and mass m, released from displacement with zero initial velocity, it is the fastest non-oscillatory return among critically damped and overdamped responses. Other initial velocities can cross the target.
      cubic-bezier()
      A CSS timing function defined by two control points. The x axis is time, the y axis is progress; y outside 0–1 means overshoot or anticipation.
      Damping ratio (ζ)
      c / (2√(k·m)). Below 1 a spring oscillates, at 1 it is critical, above 1 it creeps to rest.
      Duration token
      A named duration such as --dur-short: 200ms, so timing stays consistent across a whole product.
      Easing
      How progress is distributed over time. The shape of the curve gives motion its character.
      Ease-in / ease-out
      Accelerating from rest versus decelerating into rest. Enter with ease-out, leave with ease-in.
      Exaggeration
      Pushing a pose or movement beyond realism so it reads at a glance on a small screen.
      FLIP
      First, Last, Invert, Play: measure an element before and after a layout change, then animate the difference with transforms.
      Follow-through
      Loose parts that keep moving after the main body stops, then settle. It sells weight and inertia.
      Frame budget
      The time available per frame: 16.7ms at 60Hz and 8.3ms at 120Hz, shared by scripts, style, layout and paint.
      Interruptibility
      The ability to change an animation’s target mid-flight without a jump in position or speed.
      Jank
      Visible stutter caused by frames that miss their deadline.
      Layout thrashing
      Alternating DOM reads and writes in a loop, forcing the browser to recalculate layout again and again within one frame.
      linear()
      A CSS timing function made from a list of points, able to express bounces, elastic curves and springs.
      Momentum
      Motion that continues after a gesture ends and decays with friction, as in inertial scrolling.
      Overshoot
      Passing the target before settling back. It signals energy and elasticity; use it sparingly.
      Parallax
      Layers moving at different speeds so the eye reads depth. Keep it subtle: large parallax can trigger motion sickness.
      Perspective
      The distance between the viewer and the z = 0 plane in CSS 3D. Smaller values exaggerate depth.
      prefers-reduced-motion
      An operating-system setting that asks for less motion. Preserve feedback using immediate static state changes; a short fade is an optional alternative, not a requirement.
      requestAnimationFrame
      Schedules a callback right before the next repaint: the heartbeat of JavaScript animation.
      Restitution
      The ratio of separating to approaching relative velocity along the collision normal. For an ideal collision with unchanged effective mass, the normal kinetic-energy fraction is e², not e. Zero removes normal rebound; tangential motion may remain.
      Rubber banding
      Resistance that grows as content is pulled past its edge, followed by a spring back.
      Scroll-linked
      Animation progress tied directly to scroll position, so it can be scrubbed forwards and backwards.
      Scroll-triggered
      An animation that plays on its own clock once an element enters the viewport.
      Settle time
      How long a spring takes to stay within a small tolerance of its target.
      Spring
      Motion defined by stiffness, damping and mass instead of a duration. The duration falls out of the physics.
      Squash and stretch
      Deforming a shape while keeping its volume, to convey weight and flexibility.
      Stagger
      Offsetting the start times of a group of elements so they move as a sequence.
      Stiffness (k)
      How strongly a spring pulls toward its target. Higher stiffness is snappier.
      Velocity preservation
      Carrying the current speed into a new animation so retargeting feels continuous instead of jerky.
      View Transitions API
      A browser API that snapshots the old and new state of the page and animates between them.
      WAAPI
      The Web Animations API: element.animate() with keyframes and playback control from JavaScript.
      will-change
      A hint that a property may change, allowing the browser to prepare. It does not guarantee layer promotion or GPU acceleration. Use it sparingly and remove it when unnecessary; preparation and layers can cost memory.
