    Choreography

    Many moving parts, one readable gesture. Timing relationships explain order, preserve an object's identity and tell the eye where to look next. Design the group, not just its individual animations.

      5.1

      A little delay adds up

      A stagger turns thirty independent arrivals into a wave. Its direction can suggest reading order, a focal point or a shared source.

      Index and reverse assign one step to every item. Center and edges use distance across the grid; diagonal uses row plus column. They do not have the same longest delay. Seeded random keeps the apparent disorder reproducible, so a replay is a fair comparison rather than a new experiment.

      The group finishes at the last delay plus one item's duration. Thirty items with a 60ms index step and a 400ms duration take 2,140ms, not 400ms. Keep this tail in view when a playful entrance becomes a frequent task.

      Try itChoose index, raise the step to 100ms, and replay. Compare the last block with center at the same settings. Then set step to zero: the stagger becomes parallel.

      Key idea

      Total = max(delays) + duration. Spatial patterns can have much shorter tails than one delay per item.

      Pitfall

      Judging only the first five items. The thirtieth may still be waiting after the user is ready to act.

      How it’s builtJS
      const delays = staggerDelays(30, {
  columns: 6, pattern: 'index', step: 40, seed: 17
});
const total = staggerTotal(delays, 400);
const progress = clamp((time - delays[index]) / 400, 0, 1);
// Sample every item from the same clock; replay replaces that clock's time.
      5.2

      Schedule the relationship

      Parallel feels unified, sequential explains a dependency, and overlap gives an ordered reveal without three separate waits.

      Here the card takes 600ms, the title 400ms and the action 300ms. Parallel finishes in 600ms; sequential takes 1,300ms. At 50% overlap the starts are 0, 300 and 500ms, giving an 800ms group. The overlap fraction describes how much of the previous duration is shared, not a fixed delay.

      A visual timeline is useful only if it is the actual clock. The playhead, scrubber and three parts below all sample the same elapsed time. Pausing freezes that time; scrubbing does not launch a competing entrance, and replay replaces the current run.

      Try itPause halfway, scrub backward and choose a different mode. In overlap mode, compare 0%, 50% and 100%. The endpoints become sequential and parallel.

      Key idea

      Next start = previous start + previous duration × (1 − overlap). Compute total from the latest end, not just the final start.

      Pitfall

      Drawing a timeline that merely resembles independent CSS delays. A scrubber must control the same time that renders the components.

      How it’s builtJS
      const durations = [600, 400, 300];
const starts = schedule(durations, 'overlap', 0.5);
const total = Math.max(...starts.map((s, i) => s + durations[i]));
const local = clamp((time - starts[i]) / durations[i], 0, 1);
// Timeline blocks use start / total and duration / total too.
      5.3

      Reveal a thought, not a puzzle

      Text carries meaning before it carries personality. Choose the smallest unit that preserves a comfortable reading rhythm.

      Words arrive as phrases; characters can feel precise but extend the tail of a long sentence. Masked lines suggest a curtain rather than scattered letters. A fade is quieter than rotation, while blur deliberately postpones legibility and is more expensive to render than opacity alone.

      Splitting visual text must not split its accessible sentence. These treatments keep one intact, visually hidden copy and hide only the animated copy from assistive technology. Reduced motion reveals the whole thought immediately; it never makes someone wait for the last letter.

      Try itCompare all six styles on the same sentence. Replay twice quickly, then turn motion off mid-reveal. The readable sentence should never change or duplicate.

      Key idea

      Preserve an intact reading alternative. Visual splitting and semantic splitting are different decisions.

      Pitfall

      Announcing each arriving character in a live region. Avoid both repeated announcements and hiding the only readable copy.

      How it’s builtJS
      const pieces = splitText(sentence, { type: 'words' });
// splitText keeps a .sr-only sentence and an aria-hidden visual copy.
for (const [i, piece] of pieces.entries()) {
  const p = motion.reduced ? 1 : clamp((time - i * 55) / 420, 0, 1);
  piece.style.opacity = p;
  piece.style.transform = `translateY(${(1 - p) * 24}px)`;
}
      5.4

      One rhythm, several voices

      A loader says that work is ongoing. It does not say how much is done, and its rhythm should not pretend otherwise.

      All six designs use a deliberate 1.2-second cycle. Negative delays place neighboring pieces at different phases immediately, avoiding an awkward synchronized first beat. Dots lift, bars stretch, satellites orbit, rings expand, a wave rolls and a small grid breathes.

      Persistent motion needs an off switch. These CSS loops run only while the stage is visible, the document is active and motion is allowed. A static loading label remains even when the decoration stops. This gallery is a demonstration, not a network request.

      Try itPause and compare the silhouettes. Scroll away and return; then enable reduced motion. The loading meaning survives without any spinning or pulsing.

      Key idea

      Offset phase, not tempo. A common period makes different pieces feel like one activity.

      Pitfall

      Leaving infinite loops running offscreen, or removing the loading text when reduced motion stops the spinner.

      How it’s builtCSS
      .ch-loader i {
  animation-duration: 1.2s;
  animation-delay: calc(var(--i) * -100ms);
  animation-iteration-count: infinite;
  animation-play-state: paused;
}
[data-active='true'][data-paused='false'] .ch-loader i {
  animation-play-state: running;
}
      5.5

      Keep hold of the origin

      A list item and its detail are two views of the same thing. A shared visual gives the eye evidence of that relationship.

      The selected cover expands from its measured list rectangle to the detail header. Title, body and actions enter before that expansion has fully settled. On Back, the same clock runs in reverse from its current time, so even a change of mind halfway through opening has a valid path.

      This phone is a local panel, not a global modal. It never locks page scrolling or traps Tab. The inactive view is inert and hidden from assistive technology. Opening focuses Back; closing restores the exact source item, not simply the first item in the list.

      Try itOpen each reading, save one locally and return. Press Escape immediately after opening the third item. Try Tab out of the phone: the rest of the page is still yours.

      Key idea

      Identity includes focus. The visual origin and the keyboard return target should be the same selected item.

      Pitfall

      Waiting for an animation to finish before enabling Back. Interruptions are ordinary input, not errors to block.

      How it’s builtJS
      const first = sourceCover.getBoundingClientRect();
const last = detailCover.getBoundingClientRect();
const dx = first.left - last.left;
const dy = first.top - last.top;
const sx = first.width / last.width;
const sy = first.height / last.height;
// Interpolate translate(dx, dy) scale(sx, sy) to the identity.
// Back reverses elapsed time; it does not queue a second animation.
      5.6

      Spend attention once

      When everything asks to be noticed, the important change loses its voice.

      Both inboxes below save the same row. The chaotic version moves every row, including unchanged ones. The calm version accents only the new bookmark. This is not a contest for the smallest amount of movement; it is a test of whether movement agrees with the information hierarchy.

      The saved marker and persistent outline carry the result after motion ends. The status message names that same row in both panels. A reduced-motion user receives the same result without having to infer it from a transient gesture.

      Try itReplay, then name which item changed before reading the result. Repeat while looking only at the calm panel. Does the animation help answer the question?

      Key idea

      Animate the difference. Stable surroundings make a meaningful change easier to find.

      Pitfall

      Using motion as the only confirmation. A final marker, truthful text and accessible state must remain after the flourish.

      How it’s builtJS
      rows.forEach((row, i) => {
  const changed = i === savedIndex;
  row.classList.toggle('ch-changed', changed);
  row.querySelector('[data-saved]').textContent = changed ? 'Saved ✓' : 'Not saved';
});
// Commit the result first. Accent only the changed row in the calm panel.
      Chapter recap

      What to remember

      1. Watch the last arrival. Total stagger time is the longest delay plus the item duration.
      2. Overlap compresses an ordered sequence. A shared clock makes pause, reverse and scrub coherent.
      3. Text remains a sentence. Animated fragments are a separate visual layer.
      4. Loops need boundaries. Pause offscreen, in hidden tabs and under reduced motion.
      5. Preserve origin and focus. A local detail is not permission to lock the whole page.
      6. Give the change the spotlight. Stable context is part of the choreography.
      Check yourself0/ 3

      Thirty items, a 40ms index step and a 400ms duration. When is the group complete?

      The first item starts at zero. The last starts at 29 × 40 = 1,160ms, then needs 400ms to finish.

      At 50% overlap, when does the next part start after a 600ms part begins?

      The advance is 600 × (1 − 0.5). Half the first part's duration is shared with the next.

      One row was saved. Which hierarchy makes that easiest to find?

      Attention should agree with meaning. The persistent marker also communicates the result without motion.
