    Depth & material

    Light, occlusion and perspective turn a flat surface into a place. Use them to explain hierarchy without making meaning depend on a shadow, a pointer or a blurred plane.

      8.1

      Shadows describe distance

      A shadow is a small lighting model, not simply a black outline with blur.

      A broad, faint ambient shadow separates the card from its surroundings. A smaller, darker contact shadow anchors it near the surface. Raising the card increases offset and softness; rotating the light changes the contact shadow’s direction. This study exposes those actual geometric parameters.

      The five cards start at elevations 0–4, mapped to heights 0, 4, 8, 12 and 16px. Choose a card with a keyboard or pointer, then adjust its height. Hover adds a small visual lift, but selection and the code readout do not require hover. The gradients are static material cues.

      Try itChoose elevation 4 and rotate the light from 30° to 150°. Set its height to zero. Which shadow disappears, and why?

      Key idea

      Use two shadows for two jobs: broad separation and local contact. Their geometry should agree with the implied height.

      Pitfall

      Animating large blurred shadows on many elements can be paint-heavy. Actual cost depends on area, blur, caching and rasterization; profile rather than assuming a fixed price.

      Directional contactJS
      function contact(height, degrees) {
  const angle = degrees * Math.PI / 180;
  const x = Math.cos(angle) * height;
  const y = Math.sin(angle) * height;
  return `${x}px ${y}px ${height + 2}px -2px #0008`;
}
// Combine with a broad, low-opacity ambient shadow.
      8.2

      Perspective belongs to a space

      A small perspective distance exaggerates near and far edges. A large distance approaches an orthographic view.

      The parent supplies perspective; the rotating child preserves 3D; both faces hide their backfaces. The back is pre-rotated 180° around the chosen axis. A flat screenshot cannot substitute for that containment and transform ordering. Overflow or filters on the wrong ancestor can flatten a 3D scene.

      Only the selected face is exposed to assistive technology and keyboard focus. The toggle stays outside the rotating object. If a face contains focus when it is hidden, focus returns to that toggle before the face becomes inert. Reduced motion switches faces without a 3D journey.

      Try itFlip at 250px perspective, then 1600px. Change to the x axis. Focus the face’s link and press Escape to return safely to the front.

      Key idea

      Perspective is on the parent, preserve-3d on the rotor, backface-visibility on each face. Semantics switch independently of interpolated angle.

      Pitfall

      backface-visibility hides pixels, not focusable links. Pair it with inert and aria-hidden, and do not clip the 3D rotor itself.

      A shared 3D contextCSS
      .space { perspective: 800px; }
.rotor { transform-style: preserve-3d; }
.face { backface-visibility: hidden; }
.back { transform: rotateY(180deg); }
.rotor.flipped { transform: rotateY(180deg); }
/* Keep overflow and filter off the preserve-3d rotor. */
      8.3

      Layers are not necessarily volumes

      Small offsets can suggest a deep scene without building one. Know which illusion you are using.

      These two artworks reuse the showcase’s unchanged initTilt, including its spring-driven pointer rotation and glare variables. The exact case, case__inner, case__glare and case__layer pattern is retained. Keyboard arrow buttons add a discrete alternative around that pointer mechanism; Reset returns to neutral. The orbital artwork does not spin autonomously.

      CSS transform functions compose right to left: in rotateX then rotateY, the Y rotation is applied first to the point. Child translateZ can create actual 3D separation inside a preserved context, but these artwork layers mostly translate in x/y according to their depth multiplier. That is flat fake parallax, not a physically correct camera. On reduction or inactivity, the adapter neutralizes the rendered pose and releases the shared pointer spring.

      Try itSweep over Orbit, then focus its arrow controls and tilt right twice. Compare the foreground planet with the star field. Reset and repeat with the paper ticket.

      Key idea

      Measure the stable wrapper, rotate its inner surface and offset decorative layers. Keep hit targets outside the tilted artwork.

      Pitfall

      Calling every layer shift “3D.” Flat x/y offsets can be useful, but transform order, perspective and flattening still affect the result.

      Shared tilt contractCSS
      .case { perspective: 1100px; }
.case__inner {
  transform: rotateX(var(--rx, 0deg)) rotateY(var(--ry, 0deg));
  transform-style: preserve-3d;
}
.case__layer {
  transform: translate3d(calc(var(--px, 0) * var(--depth) * 1px),
    calc(var(--py, 0) * var(--depth) * 1px), 0);
}
      8.4

      Glass needs something behind it

      Backdrop filtering changes the pixels behind a translucent surface. Filtering the panel itself would blur its text too.

      The colorful field gives the filter actual detail to soften. Blur changes spatial detail; saturation changes color intensity. A dark translucent fill keeps the text legible even at zero blur. Neither a bright border nor blur alone guarantees contrast against arbitrary content.

      Feature detection tests both standard and prefixed backdrop-filter. Unsupported browsers use a solid surface automatically, and the checkbox lets you compare that fallback deliberately. The output names the effective material, not merely the requested value.

      Try itSet blur to zero and saturation to 200%. Then force the solid fallback. Does the text remain readable in every state?

      Key idea

      Material is progressive enhancement. A supported filter is optional; readable contrast is not.

      Pitfall

      Large backdrop filters can increase rasterization work and create stacking contexts. Cost varies with the changing backdrop, surface area and browser implementation.

      Solid firstCSS
      .glass { background: #151725; color: #fff; }
@supports (backdrop-filter: blur(1px)) {
  .glass:not(.solid) {
    background: rgb(10 12 24 / 86%);
    backdrop-filter: blur(14px) saturate(120%);
  }
}
      8.5

      A mask can invite exploration

      A spotlight is an invitation to inspect detail, not permission to hide the only copy of important information.

      The radial mask reveals a blueprint overlay on a decorated plane. Radius sets its reach; hardness controls where the opaque center starts fading. Pointer movement follows directly, without an autonomous loop. Touch taps relocate the light; arrow keys move it in deliberate steps.

      A permanent caption contains the same meaningful description outside the mask. Reveal all bypasses exploration, and unsupported masking or reduced motion shows the entire decorative overlay statically. There is no secret action or essential text to discover.

      Try itFocus the plane and press Right three times. Compare a hard edge with a soft one. Use Reveal all, then try a touch tap on a phone.

      Key idea

      Mask decoration, not meaning. Pointer, keyboard, touch and a full-reveal action lead to the same information.

      Pitfall

      Assuming a mask changes accessibility exposure. It clips pixels only; do not put invisible essential controls inside it.

      A radial alpha maskJS
      function radialMask(x, y, radius, hardness) {
  const edge = radius * hardness / 100;
  return `radial-gradient(circle at ${x}% ${y}%,
    #000 ${edge}px, transparent ${radius}px)`;
}
// Set both maskImage and webkitMaskImage on the decorative overlay.
      8.6

      Focus is a state, not a blur

      Depth of field can direct attention, but a blurred plane cannot be the only place a state is explained.

      Three overlapping study planes change scale, offset, stacking and blur when selected. The selected plane is sharp and foregrounded. The controls remain outside every filtered layer, so they stay legible and stable. Their pressed values and the readable summary identify the selected subject explicitly.

      Blur strength is applied as a static material change; only the transform gets a short transition. Reduced motion commits both immediately. If a browser cannot render blur, stacking, labels and the summary still distinguish the selection. No information depends on waiting for a plane to travel.

      Try itSelect each plane using Tab and Space. Raise blur strength, then set it to zero. Can you still tell which subject is selected?

      Key idea

      Selected state has a textual and semantic representation. Focus styling and controls must not be blurred along with the artwork.

      Pitfall

      Animating blur continuously over large regions. Static blur can still be expensive, but avoids repeatedly changing the filter during travel.

      State outside the materialJS
      function choose(buttons, selected, summary, descriptions) {
  buttons.forEach((button, i) =>
    button.setAttribute('aria-pressed', String(i === selected)));
  summary.textContent = descriptions[selected];
}
// Filter decorative planes separately; never filter these controls.
      Chapter recap

      What to remember

      1. Light explains height. Ambient and contact shadows do different work.
      2. Perspective is a shared space. Smaller distances exaggerate depth; transform order matters.
      3. Pixels are not semantics. Backfaces, masks and blur do not manage focus or accessibility.
      4. Materials need fallbacks. Solid surfaces and readable summaries survive missing support.
      5. Movement is optional. Provide stable controls and immediate reduced-motion states.
      Check yourself0/ 3

      What does reducing perspective from 1600px to 250px do?

      A nearer virtual viewpoint produces stronger perspective foreshortening.

      What is the safe unsupported-glass result?

      Backdrop filtering enhances material. Contrast and content do not depend on support.

      Where should selected state be communicated?

      Everyone should know the current state without interpreting a transient or blurred visual.
