    How to use it

    Read, play, check.

    Motion is learned in the hands, not the head. Each lesson is built so you can feel the difference between the right and the wrong version before you are told which is which.

    01

    Read

    Each lesson opens with the idea in plain language: what it is, why it works and the numbers worth remembering. A key idea and a common pitfall sit under every demo.

    02

    Play

    Every lesson has a live demo. Change the parameters, compare side by side, interrupt things mid-flight. Open “How it’s built” to see the few lines of code that make it work.

    03

    Check

    Chapters end with the takeaways and a three-question check with explanations. Mark the chapter as studied when it has clicked; the cheat sheet keeps the numbers handy.
