    Layout & continuity

    The document changes instantly. The eye needs evidence that it is still looking at the same thing. Preserve identity, geometry and focus even when someone changes their mind halfway through.

      7.1

      A layout change in four frames

      FLIP animates the difference between two layouts, not the layout algorithm itself.

      First reads the visible rectangle. Last commits the new grid cell and size, then reads its untransformed rectangle. Invert translates and scales that last box back over the first one. Play removes only the inverse transform.

      The tile below is one real element. At I, its layout is already at L, although its pixels cover F. On interruption, snapshot the in-flight pixels before cancelling the old effect. Translation is applied after scaling in this transform list, with a top-left origin.

      Try itChoose F, L, I in order. Scrub from 2 to 3. Rerun and immediately Reverse; compare the ghost outlines and numeric ratios.

      Key idea

      Read visible First, cancel, write Last, read Last, then invert. Scale ratios are first size divided by last size.

      Pitfall

      Cancelling before the first measurement loses the current pose. Scaling text may also look distorted; production grids can separate their background and content layers.

      The inverseJS
      function inverse(first, last) {
  return `translate(${first.left - last.left}px, ${first.top - last.top}px)
    scale(${first.width / last.width}, ${first.height / last.height})`;
}
// element uses transform-origin: 0 0; first includes in-flight transforms.
// After committing layout, animate inverse(first, last) to 'none'.
      7.2

      Many objects, stable identities

      A grid has arrivals, departures, reorders and changes inside each tile. They need different treatment.

      This is the showcase’s unchanged initFlip study. Its snapshot records both tile and color-layer rectangles. After cancelling previous effects, the DOM is sorted or filtered, then translation moves the tile while an independent inverse reshapes its color layer. List mode is a genuine layout change, not a picture of one.

      Filtered items leave layout immediately. Temporary, noninteractive, aria-hidden ghosts fade where they used to be; returning items enter from a small scale. A swatch opens the shared global dialog, whose overlay lives outside this clipped stage. The close action restores the exact source focus. Filters keep their radio-keyboard contract.

      Try itShuffle, filter Warm with the arrow keys, sort twice and switch to List. Open a swatch, then press Escape while it is still expanding.

      Key idea

      The same element survives the reorder. Leaving decoration is not a second interactive copy.

      Pitfall

      A fixed modal inside an isolated, overflow-hidden stage may be clipped or trapped in the wrong stacking context. Keep the overlay at main level.

      7.3

      Auto height is not one problem

      Ask whether surrounding content must move before deciding how to reveal a panel.

      Max-height interpolates a guessed cap. With a 280px cap and 140px content, a linear opening finishes visibly halfway through its nominal duration; content above the cap clips. Grid 0fr → 1fr works with a min-height: 0, overflow-hidden child and adapts to natural content without a guessed cap.

      Measured height reads the content’s scrollHeight, animates from the currently rendered height and returns to auto when open. Content or width changes require a fresh measurement. ScaleY changes only the picture: the next sibling stays below the original space. All four disclosures remove collapsed links from focus immediately.

      Try itToggle all, grow the answers and narrow their containers. Watch the sibling marker under ScaleY; compare the measured boxes, then reverse a JS-height close.

      Key idea

      Real height and grid-track animation reflow siblings. A transform does not. Choose based on the relationship you need to explain.

      Pitfall

      Zero pixels is not the same as hidden from interaction. Restore focus before applying inert and aria-hidden to a collapsing answer.

      Natural-height gridCSS
      .answer { display: grid; grid-template-rows: 0fr;
  transition: grid-template-rows 350ms ease; }
.answer.open { grid-template-rows: 1fr; }
.answer > div { min-height: 0; overflow: hidden; }
/* Set inert and aria-hidden separately; CSS is only presentation. */
      7.4

      Snapshots are asynchronous

      A browser-managed transition can preserve a cover across a local layout change, but it does not own your application state.

      Newer browsers provide document.startViewTransition; older browsers still need a fallback. The native engine captures old pixels, invokes the update callback and captures the new view. Unique names match visible covers across those snapshots. Here the actual cover node and ID also survive, moving into the detail slot.

      Skipping a transition does not cancel its update callback. This study invalidates older revisions, calls skipTransition, handles ready rejection, and waits for updateCallbackDone and finished before a new capture. Only the latest revision may update or focus. The fallback uses current-rectangle FLIP plus a content fade. Reduced motion commits instantly.

      Try itOpen Night lines, go Back immediately, and reopen another cover. Force the fallback while opening. Tab outside: this is local detail, not a focus-trapping modal.

      Key idea

      Separate requested state from captured state. A revision owns both the DOM update and the focus change.

      Pitfall

      Ignoring ready rejection after skipTransition, or letting an old callback hide a newly reopened panel. Duplicate visible transition names can also prevent the native animation.

      Cancellation barrierJS
      async function drain(previous) {
  if (!previous) return;
  previous.skipTransition();
  await Promise.allSettled([
    previous.ready, previous.updateCallbackDone, previous.finished
  ]);
}
// Await drain(active), then check the request revision again.
// A guarded update callback alone is not a cancellation barrier.
      7.5

      Interpolate topology, not intent

      A path morph is arithmetic on corresponding coordinates. The browser cannot guess which corner should become which curve.

      Each pair below has the same command letters, command count and number of numeric values. The play triangle is split into compatible polygons so it can become two pause bars. Menu and check use two line segments; the organic shapes share four cubic curves. Compatible numbers are necessary, but their visual correspondence still needs authoring.

      The hit area is always a native button, separate from the changing SVG. Labels and pressed state describe the selected endpoint, not media playback. Scrubbing selects a pose; reduced motion snaps to the nearest endpoint, and live preference changes settle the latest requested shape.

      Try itToggle all four shapes. Select Blob, scrub to 0 and 1, then inspect its path readout. Replay and reverse an icon before its morph finishes.

      Key idea

      Matching command topology makes numeric interpolation possible. Stable buttons and text carry the interaction semantics.

      Pitfall

      Mixing relative and absolute commands, or interpolating boolean arc flags. Even a compatible path can fold over itself if points are paired badly.

      Shared pure interpolatorJS
      import { createMorph } from '../core/morph.js';
const menu = 'M4 7 L20 7 M4 17 L20 17';
const close = 'M6 6 L18 18 M6 18 L18 6';
const sample = createMorph(menu, close);
const halfway = sample(0.5); // M5 6.5 L19 12.5 M5 17.5 L19 11.5

      7.6

      Rank is not identity

      A player remains the same person when their position changes. Key by player, never by rank.

      Each local round adds a deterministic score increment. Existing list elements are reordered in the actual DOM, so visual, reading and accessibility order agree. First rectangles include unfinished transforms; after cancellation, the new order supplies Last rectangles. Scores use the shared rolling-number component, while podium badges name the final rank.

      The status announces the final order once per action, not each intermediate digit or frame. Reset restores the initial scores and ordering. These are mock rounds, not live network data; deterministic increments make interruption and parity checks repeatable.

      Try itAdvance three rounds quickly and track Mira, not the first row. Reset twice; the names, scores and podium should return to the same result.

      Key idea

      The key identifies a player. Sorting changes location, not the element or its accessible identity.

      Pitfall

      Using CSS order alone can leave reading order behind. Replacing the whole list also loses focus and any per-player interaction state.

      Reproducible roundsJS
      function increment(playerIndex, round) {
  return ((playerIndex + round * 2) % 5) * 17 + 3;
}
// Add to each score, then sort descending; break ties by original index.
// Snapshot existing keyed nodes before reordering them, not after.
      Chapter recap

      What to remember

      1. Measure the current picture before cancelling. Commit layout once, then animate the inverse.
      2. Height is about flow. Scale changes pixels, not sibling allocation.
      3. Snapshots need ownership. Skip, drain promises and guard updates with a revision.
      4. Topology is authored. Matching commands do not guarantee a good-looking morph.
      5. Identity includes focus and DOM order. Preserve both through interruption.
      Check yourself0/ 3

      What comes immediately before cancelling an in-flight FLIP?

      The visible geometry includes the unfinished transform. Cancelling first loses that continuity.

      What does numeric SVG interpolation require?

      Each coordinate needs a corresponding coordinate. Arc flags must agree rather than interpolate.

      Which collapse leaves the next sibling’s layout position unchanged?

      A transform changes the rendered picture, not the box’s contribution to normal flow.
